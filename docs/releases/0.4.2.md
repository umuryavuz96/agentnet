# agentnet 0.4.2

Fixes from a fresh install.

- "Start director for me" starts the director in the tmux session that "Open window" looks for, so Open window works.
- If you started the director in your own terminal, "Open window" brings that terminal app to the front, or tells you where the director runs.
- First-run setup has a "Choose…" button that opens the system folder dialog (macOS; Linux with zenity). You can still type the path.
- Shipped hooks (prompt triage, usage guard, task guard) show their runs on a fresh install.

Update from the header pill, or run `agentnet update`.
