# agentnet 0.5.3

Adopt can now switch off the old message system for you: hooks in many repos and the MCP server in your own Claude Code settings. The After adopt summary is easier to read.

**Park for me**

- Hooks across repos: one finding can switch off the inbox hook in every repo, including each repo's `settings.local.json`. The card lists the repos with a checkbox each, so you can leave one running.
- Your own MCP server: an MCP server registered in `~/.claude.json` can be switched off too. agentnet moves only that entry into its backup and leaves every other byte of the file as it was. Undo puts the entry back, even if Claude Code changed the file in the meantime. Secrets in the entry stay out of the plan, the preview and the run log.
- The old message system itself no longer shows as "do by hand". Once its hooks and server are parked, the card reads "Parked by the actions above". If you keep any of them, it reads "Keeps running beside agentnet".
- The scan now prefers real actions over "do by hand". Hand steps are left for things like a running tmux session, a launch agent or a cron line.

**After adopt summary**

- One line on top: the director, how many things keep running, how many are switched off.
- Sections are stacked instead of three narrow columns. Hooks are grouped by repo, closed by default, and open with an animation.
- Plain names such as "Stop hook: runs check-inbox.sh", short paths with the full path on hover, and a clear label where a command was hidden because it held a secret.
- It follows your choices live: a repo you leave on moves to "Keeps running".

**Large `~/.claude.json`**

- The scan could not read `~/.claude.json` once it grew past 200 KB, so MCP servers there were never seen. That file is now read up to 16 MB, for MCP entries only.
