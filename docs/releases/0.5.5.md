# agentnet 0.5.5

The director now always starts with the agentnet plugin, or tells you why it could not.

**Director setup**

- If the director could not join agentnet (for example agentnet did not answer), Claude Code no longer starts without the plugin and sits at an empty prompt. The start stops and the page shows the reason.
- The join call no longer goes through a network proxy set in your environment. On a work laptop with a proxy, this call to your own machine failed without a message.
- If Claude Code is ready but the director does not say hello within 15 seconds and the plugin was not passed to it, the page says so and offers Retry.
