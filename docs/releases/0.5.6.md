# agentnet 0.5.6

The director can now join after an earlier setup attempt left a stale entry behind.

**Director setup**

- In "Adopt my workspace", the scan session registers as the director too. It is now removed when the scan is applied or cancelled, so the real director can join at step 7. Before, step 7 failed with "root is live already" and Retry could not help.
- Setting up the director also no longer fails when an earlier attempt left an entry that never connected. An entry that never said hello within a minute, or whose process and session are gone, is replaced. A director that is really running still blocks a second one.
