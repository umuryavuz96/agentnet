# agentnet 0.7.2

Resume director works after a restart. Tapping an agent card opens a rebuilt chat, the 2D map and agent cards are redrawn, and apps can pair with the service instead of copying a token.

## Director

- **Resume director works after a restart.** On a director with its own Claude config dir and account token, the start command gave both only to `cd`. Claude started at the login screen and Resume looked like it did nothing. Both now reach Claude, and Resume finds the earlier conversation.
- Resume and Start fresh also work on installs that require a token on every call.

## Chat

- Tapping an agent card opens that agent's chat as a side panel. Drag it, resize it from any edge or corner, expand it to full view, and go back with Esc. A small Details button on the card opens the side panel with Now, Trail and Usage.
- The agent's work reads as a trail: tool calls fold into one line, follow the plan steps and open to show input and output. Written and edited files show their content or diff. Messages between agents appear as trail rows.
- Replies can show cards for files, tasks, drafts, results and Jira tickets, text markers (see `docs/CHAT-TEXT-MARKERS.md`) and live UI that an agent draws in a sandbox with no network (see `docs/CHAT-UI-BLOCKS.md`). Agents are told about the markers.
- Paste or drop pictures into the composer. Pictures open large in place.
- Replies arrive faster. Older messages load as you scroll up and keep your place.
- When your message waits for a busy agent, the chat says so and offers **Send now**.
- New composer settings: which key sends, queue or interrupt, text size, quick prompts, and starting tool calls expanded.
- A closed agent's chat says it is closed. The "no connection" banner shows only when the service is down.

## Owner messages through the plugin

What you type to an idle agent now goes through its plugin, as your own prompt (Claude Code 2.1.286 or later). The director, older agents, messages sent during a turn, **Send now** and **Stop** still use tmux. Set `AGENTNET_OWNER_VIA_PLUGIN=0` to type every message through tmux.

## Pairing apps

An app with no token can now ask for one. You approve or deny it on Asks, using a short code. Settings has a Devices card that shows each paired app's last use and revokes it. Revoking closes the app's open stream at once.

## Map and cards

- The 2D map and the agent cards are redrawn: a team is a node and its agents hang under it. Each agent has its own colour, and idle cards are greyed.
- The map has more room: the controls float over it. The agent and team panels can be resized.
- `#/asks?check=<id>` opens one question directly.

## Evals

- A fixed exam per brain: a task miner, an isolated runner with hidden checks, and a read-only **Evals** page with pass rate and cost charts.
- Lessons kept in a brain file load only when `AGENTNET_BRAIN_LESSONS=1`.

## Fixes

- A done report no longer answers 500 on a goal that has owner items.
- A message that arrives as an agent's turn ends now starts a new turn, so the agent no longer sits idle with it unread.
