# agentnet 0.4.1

Fresher status lines on agent cards.

- The line under each agent on the map now follows the newest signal: tool use in plain words ("Running tests", "Type-checking", "Editing App.vue"), then the task in progress, then the agent's own status text.
- After a minute without activity the card says "Idle · last: <what it did> <when>".
- Blocked agents, open owner checks and agents waiting for a reply show that first.
- Fix: the Linux CI test for the systemd update mode.

Update from the header pill, or run `agentnet update`.
